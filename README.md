## Selected work

### [Session Journey](https://github.com/esa-zz/session-journey)

Minimal append-only episodic memory for coding-agent sessions.

Coding agents can lose useful history after context compaction or a restart. Session Journey keeps discoveries, failed approaches, decisions, corrections, blockers, and pivots in append-only Markdown files.

I kept the format simple on purpose. Markdown works with Git, grep, editors, and normal file tools. Old events are never rewritten. If something turns out to be wrong, the agent adds a correction instead.

The project also keeps task state and project documentation out of the memory file. Those already have better places to live.
